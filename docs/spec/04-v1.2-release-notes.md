## 4. Defects found and fixed while building v1.2

| Where | Defect | Fix |
| --- | --- | --- |
| `src/notifications/scheduler.ts` | `enableReminders` cancelled **every** previous identifier, including the independent refill (`rotation`) schedule, while keeping its id in state. | Cancels only `{ checklist, zone }`; the refill schedule survives the main toggle. |
| `src/app/inventory.tsx` | The `EntryEditor` saved nothing for kit lines that were not yet tracked. | The screen now writes `{ [line.id]: { ...next, itemId: line.id } }`. |
| `src/i18n/en.ts`, `src/i18n/es.ts` | `comms.checkin.hours` had no `{hours}` placeholder. | `Every {hours} h` / `Cada {hours} h`. |
| `src/app/go-bags.tsx` | In the empty state, "Add a blank bag" set the editor open but never rendered it — a dead button for a household with no bags. | The editor is now a shared element rendered in both the empty and the populated state. |
| `src/app/drill/[id].tsx` | `Date.now()` was called during render (React purity violation, and a lint error). | The drill's own countdown is the clock; elapsed time is derived from it. |
| `src/ui.tsx` | The progress bar had no `accessible` prop, so Android never announced its label or value. | The track is now an accessible `progressbar` element. |

## 5. Craft pass (motion and interaction)

The v1.2 screens inherited the v1.1 UI kit. This pass tightened the shared primitives so every
new screen inherits the same feel.

| Before | After | Why |
| --- | --- | --- |
| `Action` scaled to `0.975` over 110 ms; `MotionPressable` scaled to `0.97` over 120 ms | One `PRESS_SCALE` / `PRESS_DURATION_MS` pair, and `Action` now renders through `MotionPressable` | Two nearly-identical press feels in one app is the kind of inconsistency users feel without naming. |
| Press release used `withTiming(1, …)` | Press release uses `withSpring(1, { damping: 18, stiffness: 320 })` | A spring settles on whatever velocity the press had, so a quick tap-and-let-go never looks cut short. |
| `Action` wrapped its `Pressable` in an `Animated.View` | The scale is applied to the pressable itself | One fewer view node per button, and the scale tracks the real hit target. |
| The progress bar set `width: '<percent>%'` | The fill is a full-width bar scaled on `scaleX` with `transformOrigin: 'left'` | Animating `width` re-lays out every frame; a transform stays on the compositor thread. |
| The switch thumb jumped between positions | The thumb travels on a spring (`damping: 20, stiffness: 260`) | A switch is the most physical control in the app; it should read as an object being flicked. |
| New v1.2 editors appeared and vanished with no transition | A shared `Disclosure` primitive fades them in over 120 ms and out over 100 ms | The v1.1 Plan screen already did this; the v1.2 editors were inconsistent with it. Enter is slower than exit so a panel that opens feels considered and one that closes gets out of the way. |
| The drill runner swapped steps as a jump cut | Steps fade and slide (`FadeInDown` in, `FadeOutUp` out) | The steps advance in order, so the motion should say "forward". |

All motion respects the device's reduced-motion setting: `useReducedMotion()` gates the scale and
the springs, and every layout animation is declared with `reduceMotion: ReduceMotion.System`.

## 6. Known cuts and limits

- **English copy in v1.1 screens stays English.** F10 localizes every *new* v1.2 screen and section
  in full. v1.1 screens keep their long-form English copy, and shared/exported text stays in its
  source language. This is a documented scope decision, not an oversight.
- **Notifications and the app lock are native-only.** The web build no-ops both by design
  (`expo-notifications` has no web scheduler; `expo-secure-store` has no web implementation, so
  the PIN lock stays off there).
- **Device checks are still manual.** The plan's §10.3 regression checklist and §10.4 device matrix
  need physical hardware: airplane-mode passes, the two-device export/import round trip, the
  notification channels, the app lock after 5 minutes in the background, the wipe, and the
  TalkBack/VoiceOver walkthrough at 130 % font scale in both languages.
- **WS-D copy review is outstanding** for the new strings (medical, drills, readiness, Spanish
  content, privacy copy).
